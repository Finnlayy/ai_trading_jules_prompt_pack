# Implementation Plan - Kraken Paper Trading PnL & History Fixes

This plan addresses two main issues in the Kraken paper trading engine:
1. **Trade History logging**: Currently, closing/reducing a position creates a new trade in the database with `entry_price = exit_price = fill_price`, showing a non-zero PnL for zero price movement, and leaves the original opening trade row as `"open"` forever. We will refactor this to update the original trade row to `"closed"`, linking the correct entry price, exit price, and PnL.
2. **Ledger Reconciliation**: The `reconcile_ledger` method double-subtracts the initial purchase cost of closed trades from the USD cash balance because it processes both the original trade (still `"open"`) and the closing transaction row. We will simplify and correct this formula.

## Proposed Changes

### Kraken Paper Trading Broker

#### [MODIFY] [kraken_paper_broker.py](file:///g:/Downloads_Sortiert_2026-05-20/ai_trading_jules_prompt_pack/app/services/kraken_paper_broker.py)

1. Refactor `place_paper_order()`:
   * Do not automatically create a new `PaperTrade` at the beginning of the method.
   * If the order is an opening order (`LONG` when no position or same direction):
     * Create a new `PaperTrade` with `status="open"`.
   * If the order is a closing order (`SHORT` reducing/closing a `LONG` position):
     * Query all open `PaperTrade` rows for this symbol (ordered by `created_at` ascending).
     * For each open trade, split it or mark it closed:
       * If `volume_to_close >= open_trade.volume`:
         * Update the open trade: `status="closed"`, `exit_price=fill_price`, `pnl=(fill_price - open_trade.entry_price) * open_trade.volume`, `closed_at=now`, `fee += proportional_close_fee`.
       * If `volume_to_close < open_trade.volume`:
         * Split the open trade: Create a new closed `PaperTrade` representing the closed portion, and reduce the `volume` and `fee` of the original open trade.
     * If the order is a flip (opposite direction with larger volume):
       * Close all open trades first.
       * Create a new open `PaperTrade` for the remaining flipped volume.

2. Refactor `close_paper_position()`:
   * Instead of creating a new closed `PaperTrade` row with `entry_price=exit_price=fill_price`, find the open `PaperTrade` rows and close/split them using the same logic as above.

3. Refactor `reconcile_ledger()`:
   * Correct the expected balance formula:
     ```python
     expected = self.config.initial_balance_usd
     for t in trades:
         if t.status == "open":
             if t.direction == "LONG":
                 expected -= (t.entry_price * t.volume + t.fee)
             elif t.direction == "SHORT":
                 expected += (t.entry_price * t.volume - t.fee)
         elif t.status == "closed":
             if t.pnl is not None:
                 expected += (t.pnl - t.fee)
     ```
